# side-explainer · 侧推讲解
**什么时候用**：人物正在全屏讲话，开始讲"某个工具/方案的功能、优势、组成"时。按人物素材自动选两种做法（用户定稿）：
- **横拍素材（16:9）**：参考风格 D3——整幅人物画面推到右侧并轻推近，让出的左侧压一层由深到透的渐变遮罩，房间仍隐约可见。
- **竖拍素材**：裁成一块大小适中、带圆角的人物卡放到右侧（上下不顶边，约 82% 画面高），身后露出品牌文字墙（`wallSkin`），不用模糊铺底。
- **竖屏画布（9:16 / 3:4）**：人物裁成上方一块宽幅圆角卡，下面是结论和演示区（box 写 `demo` / `quote`，自动按画幅换位置）。

左侧（竖屏是下方）演示区按逐字稿一拍一拍换演示；叠卡逐张出现——新卡盖在前面、旧卡后退变暗；卡内图标块用分支线连到要点行；最后一句结论发光逐字亮起。
**语义对齐**：每张卡写 `"cue"`（说到这个功能名时盖上来），每个要点写 `"cue"`（说到这个词时连线画过去、要点亮起），引用写 `quoteCue`（说到这个词时亮起）。
**文案**：卡标题 ≤ 8 字、副标题 ≤ 26 字、要点 ≤ 8 字 + 说明 ≤ 14 字；引用写这段的结论，不要照抄整句字幕。
**之后**：下一段要么回到全屏（`{"state":"full"}`），要么换成圆窗/卡片；不要一直停在侧移状态超过 20 秒。人物要在左侧时：presenter 写 `"pos":"l"`，并把两个层的 box 镜像到右侧（x 改成 0.46）。
