# 口播剪辑语法（从 9 条高流量参考片提炼）

这份是"说到什么时候、画面该呈现什么"的规则书。规划每一条片子前先读一遍。逐片拆解见 [reference-videos.md](reference-videos.md)。

## 0. 一句话原则

**字幕负责"说了什么"，画面负责"证明它"。** 画面元素只在说出关键词的那一刻出现，一段话只讲一件事，人物是同一个对象在画面里移动，不是每段重新开场。

## 1. 时间：说到哪个字，画面就落在哪个字

实测风格 A（A1）的关键词与画面对齐误差：

| 说到 | 口播时刻 | 画面出现 | 差值 |
|---|---|---|---|
| 不可能 → 可能 | 37.49 / 38.83 | 划掉 37.5 / 盖章 38.8 | ≈0 |
| 免费 | 69.87 | FREE 印章 69.8 | −0.1 |
| 百分之一 | 80.41 | <1% 80.3 | −0.1 |
| 整理 / 上传 / 分享 | 131.8 / 132.7 / 134.1 | 三个胶囊 131.7 / 132.6 / 133.9 | −0.1~−0.2 |
| 每晚九点 | 129.0 | 时钟卡 126.0 | −3（场景容器先到） |

由此得到默认值（技能里 `cue` + `lead` 自动实现）：

- **关键词元素**（数字、标签、印章、胶囊）：提前 **0.10–0.20 秒**（`lead: -0.15`）。出现动画本身 0.2–0.4 秒，落定刚好压在字上。
- **情绪词**（夯爆了 / 震惊 / OMG）：**正好压在字上**（`lead: -0.05`~`-0.3`，砸字类动画有 0.15 秒蓄力）。
- **场景容器**（新背景、卡片框、时钟、窗口）：在**这句话开头**出现，比关键词早 0.5–3 秒，先给观众一个"舞台"。
- **结论 / 胜者揭晓**：在说出结论那个词时（`winnerCue`），不要提前剧透。
- **同一段里元素间隔 1–2 秒**；低于 0.8 秒观众读不完，高于 4 秒画面会显得"停了"。

## 2. 节奏：段与元素

- **一段 = 一个语义单元**，5–15 秒。段与段之间换背景或换版式（= 观众感知的"翻页"）。
- **段内逐个累加**：每 1–2 秒加一个元素，跟着口播一个个"点亮"，最后形成一屏完整信息，再翻页。
- **开头 3 秒决定完播**：第一句就要有画面钩子——结论巨字（打通了！/ 逐字稿工作流）、数字证据（81 种 / X 万粉）、冷开场梗（再见·高调退场）。真人全屏 + 一个巨字是最稳的开场。
- **全片节奏曲线**：开场高 → 讲解中 → 演示中高 → 情绪点高（彩纸/印章）→ 总结中 → 结尾 CTA 高 → 道别低。配乐能量（`energy` 0–3）跟着这条曲线走。
- **硬切数量**：教程类每分钟 6–8 次切换（D2 1222 秒 153 次），观点类每分钟 2–3 次且多为推/拉/滑的连续过渡（C1 443 秒几乎零硬切）。

## 3. 人物：一个人物对象，六种形态，连续迁移

| 形态 | 引擎状态 | 什么时候用 | 参考片 |
|---|---|---|---|
| 全屏 | `full` | 开场、讲观点、讲情绪、讲故事、结尾道别 | 全部 |
| 全屏 + 推近 | `full` + `zoom 1.12`，`dur 0` 为跳切 | 每 8–15 秒换一次景别制造节奏；说重点时推近 | 风格 C |
| 侧移 + 讲解底板 | `side` + `pos` | 人物正讲着，开始列某个工具/方案的功能、优势、组成：人物和全屏时一模一样、干净地整幅推到一侧（不羽化、不加模糊），让出的一侧放半透明底板（能隐约看到背景）再放叠卡（比缩成卡片更"不打断"，人还在原来的房间里） | 风格 D3 |
| 侧边卡片 | `card` / `story`（大卡） | 一边说一边展示（人物占 30–36%，内容占另一侧） | 风格 A、B2 |
| 角落圆窗 | `circle` + `pos` | 内容需要整屏空间时（演示、录屏、图表），人物当讲解员 | 风格 A、风格 C、术语 |
| 圆角小方窗 | `pip` | 录屏/界面演示，和圆窗二选一保持全片一致 | 术语、D2 |
| 软件窗口 | `window`（带标题栏） | 介绍工具时，人物和产品"同屏并列"，像两个 App 窗口 | 风格 C2 |
| 大圆居中 | `circle-big` | 直接对观众喊话、结尾"谢谢大家" | A1 结尾 |
| 抠像站位 | `cutout`（需 `matte`） | 人物"站"在 MG 场景里用手势指挥对象 | 风格 C3 |
| 隐藏 | `hidden` | 画面主体是录屏/成片，且当时没有真人画面 | — |

迁移规则：
- **同一个对象**：从全屏缩成卡片、从卡片缩成圆窗，位置、尺寸、圆角、边框一起插值（引擎默认 0.6 秒、端点速度为零的 smooth 曲线）。
- **圆窗换角落跟着内容走**：内容主体在左 → 人物去右下；录屏重点在右上 → 人物去左下。每换一个场景可以换一次角落，**过渡色块里保持不动当锚点**（A1 47 秒紫色过渡页）。
- **放大 = 拉近与观众的距离**：说"我会帮你实现""欢迎留言""谢谢大家"时把圆窗放大（A1 1:00 红色放射页）。
- **人物窗变化间隔 ≥ 0.8 秒**，否则观众会晕（`lint` 会提示）。
- **竖拍素材放横屏**：默认"居中竖条 + 模糊铺底"（`fullFit: contain`），不要硬裁掉头和手。

## 4. 语义 → 画面对照表（核心）

先问这句话的"对象、关系、动作、结果"是什么，再选组件。复杂度来自关系和状态变化，不来自卡片数量。

| 口播里出现 | 视觉语言 | 组件（引擎名） | 参考 |
|---|---|---|---|
| 结论 / 成绩 / 反差 | 巨字砸下 + 微震 | `title` reveal=slam、`stamp` | 打通了！、夯爆了 |
| 数字 / 价格 / 百分比 | 巨号数字滚动定格，单位小字，黄色 | `number`、`gauge` | X 万粉、¥129/月、<1% |
| 前后对比 / 成本下降 | 两条长条 → 缩短 + 红箭头 | `bars`（`to` 收缩） | 时间成本 / token 成本 |
| A vs B / 几个方案 | 卡片逐张入场 → 胜者描边放大，其余变暗 | `compare`（`winnerCue`） | GPT 裸跑 vs Opus |
| 以前 → 现在 / 手动 → 自动（前后反差） | 一张卡上分割线扫过，旧状态变灰被新状态替换 | 动效库 `fx-before-after`（`revealCue` 落在「现在」） | — |
| 工程文件 / 导进剪映、PR / 还能改字幕改音乐 | 剪辑软件时间线，光标点中片段当场改 | 动效库 `fx-editor-timeline`（`edits[].cue` 落在「改字幕」「改音乐」） | — |
| 点赞、收藏、关注（求三连） | 三颗按钮按口播逐个按亮 | 动效库 `fx-cta-buttons`（每个按钮 cue 落在对应的字） | — |
| 开源 / 放到 GitHub / 免费给大家用 | 仓库卡浮起 + 开源印章 | 动效库 `fx-repo-card`（`stampCue` 落在「开源」） | 仓库名、账号用用户真实的，不编星标数 |
| 评论区告诉我 / 我挑几条来做 | 评论区面板逐条选中 | 动效库 `fx-comment-pick`（`pickCue` 落在数字） | 评论是示意，保留"示例"角标 |
| 片头 solo 里"演示它怎么剪" | 原创小角色在画面里点、踩、滚、放技能，碰到哪里哪里就变 | 动效库 `fx-play-sprite`（放 globals，路径按元素实测坐标写） | 不用任何公司的标志当角色 |
| 片头 solo / 发布感开场（口播前的纯动效展示） | 电影感地平线 + 衬线品牌字 → 鼓点进来每拍闪一个动效 → 大字砸下收住 | 动效库 `fx-horizon-title` + 0.5s 一镜的快剪（结构见 SKILL.md 片头 solo） | 只放使用者自己的品牌，不搬任何官方宣传片的标志和素材 |
| 翻页 / 翻书 / 换个话题（快速切换几个话题） | 整屏像书页一样翻走、翻回 | 转场 `page` → `page-back` | 每页只放一个大标题，0.5–1s 一页 |
| 否定 → 肯定 / 改口 | 划掉 → 红底改写盖章 | `strike` | 不可能 → 可能！、D2 → B2 |
| 第一 / 第二 / 第 N 个 | 巨号章节 #2 + 标题横移 | `chapter`、`fx-chapter-tag`、`fx-flap-title` | #2 第二个兴奋点 |
| 一串名词 | 标签在人物两侧左右交替弹出 | `tags` | LLM / Token / Agent / RAG |
| 列举 2–5 项 | 胶囊逐个出现 / 清单逐条打勾 | `chips`、`checklist` | 给我点时间 / 主包也有很多事 |
| 步骤 / 流程 | 步骤卡 + 连线逐段画出，当前步高亮 | `flow` | 整理 → 上传 → 分享 |
| 过程 / 等待 / 执行 | 任务进度条 + 确认弹窗 + 完成章 | `progress` | Agent 执行中 35% → 100% |
| 一个东西由几部分组成 | 中心节点 + 卫星 + 流动光点 | `nodes`、`fx-mind-tree`、`fx-cycle` | AI 基础 → FDE/GEO/MCP |
| 积累 / 记忆 / 越来越多 | 一摞摞条纹卡逐渐长高 | `stacks` | AI Bot 记忆堆叠 |
| 海量 → 筛选 | 网格逐格填满 → 少数高亮 | `grid` | 成千上万的答案 → 橙色方块 |
| 时间 / 历史 / 计划 | 时间线节点，当前节点放大 | `timeline` | 10.22 → 11.3 今天 |
| 他说 / 我问 / 对话 | 对话气泡回放，AI 先打点再出字 | `chat`、`bubble` | Claude 问答 |
| 提示词 / 命令 / 搜索 | 输入框逐字打出 → 点发送 | `type` | 给 <产品> 做 20 秒宣传片 |
| 网友说 / 评论 | 引用卡左右交错飞入 | `quote` | 网上测评说… |
| 通知 / 私信 / 涨粉 | 手机 + 角标数字跳涨 + 消息下滑 | `phone` | 私信 12 → 99+ |
| 软件 / 网站 / 录屏 | 窗口里放真录屏，点击处放大 + 光标 + 便签 | `window`（zoom/cursor/callouts/highlight） | D2 |
| 文档 / 稿子 / 标注 | 文档卡逐行高亮 + 侧边批注 + 字数计数 | `doc` | 逐字稿：语气词/口误 |
| 产品名 / 品牌 | 真实 logo 玻璃卡（念到名字时弹出）/ 金属大字 | `logo`（`src` 放官方图标，`size` `row`） | Claude、Codex、豆包 |
| 情绪爆点 | 彩纸 / 速度线 / 贴纸 emoji | `confetti`、`burst`、`sticker` | 太兴奋了！😂 |
| 等式 / 定义 | A = B 分立人物两侧 | `equation` | Bot = 子Agent |
| 自我介绍 | 名牌巨字 + 账号小字 | `namecard` | A1 结尾自我介绍名牌 |
| 它有几个优势 / 功能 / 能做哪些事 | 人物侧移 → 遮罩上叠卡：标题 + 图标块分支连到要点行；讲下一个优势时新卡盖上来，旧卡后退变暗；最后一句结论发光 | presenter `side` + `demo-zone`（按 4.5 节每拍换演示）+ `glow-quote`，或 `fx-side-caption` 配内容区 | D3 办公协同 |
| 指向画面某处 | 圈选 / 荧光笔 / 箭头 | `mark`、`arrow` | 背景也在动 |
| 关注 / 点赞 / 下期 | 放射光 + 云朵 + 三按钮 + 大圆人物 | `fx-follow-card`、`fx-next-episode`、`fx-end-brand` | A1 结尾 |

**表里没有合适的**：先 `dms.py catalog 关键词` 搜一遍完整目录（references/catalog.md，组件 / 动效库 / 328 张原卡 / 已装行业包的模板；原卡用 `dms.py card` + `replace` 改成本期内容）；还没有，按 SKILL.md「动效不够时」现做一个新动效（质量关见 quality.md：风格 A–D 都是参照，风格 C 最贴近用户口味），检查通过后自动沉淀进 `effects/` 动效库，下次这张表就多一行。

**不要做的**：
- 把整句字幕再用大字排一遍（captionRepeat）。大字只放 ≤12 字的结论或关键词。
- 每句话换一套背景。同一个话题共用一面墙、一个窗口，只换前景元素（A1 每章一个背景、风格 C全片一面墙）。
- 编造事实。示意内容要么来自口播原话，要么标"界面示意"；对比卡的文案不能替博主下他没说过的结论。

## 4.5 演示区语义对照（侧推讲解：人物在一侧，另一侧是演示区）

演示区不是固定的"一个图标块 + 几条要点"。**逐字稿每换一个意思，演示区就换一拍**（`demo-zone` 的 `beats`），每拍选最贴切的那种演示，口播说到哪个词，这一拍里对应的东西就在那个字上出现。

| 这一句在讲 | 演示区变成 | 组件 / 写法 |
|---|---|---|
| 它有几个功能 / 优势 / 能做哪些事 | 叠卡：标题 + 图标块分支连到要点行，下一个优势时新卡盖上 | `panel-stack`（每条要点 `cue`） |
| 我问它 / 它回答 / 对话过程 | 对话框回放：我的气泡 → AI 先打点再出字 | `chat`（每条 `msgs[].cue`） |
| 我输入了一句提示词 / 命令 | 输入框逐字打出 → 点发送 | `type`（`submitCue` 落在说完那句） |
| A 和 B 比 / 以前 vs 现在 | 两张卡逐张入场 → 胜者高亮；或长条缩短 | `compare`（`winnerCue`）/ `bars` |
| 分几步 / 先…再…最后 | 步骤卡 + 连线逐段画出 | `flow`（`dir: col`，每步 `cue`） |
| 它在跑 / 执行中 / 等它做完 | 进度条 + 确认弹窗 + 完成章 | `progress` / `checklist`（日志式） |
| 一个数字 / 时长 / 倍数 / 百分比 | 巨号数字滚动定格 + 单位 | `number` / `gauge` |
| 由几部分组成 / 连着很多东西 | 中心节点 + 卫星 + 流动光点 | `nodes` |
| 时间顺序 / 版本演进 | 时间线，当前节点放大 | `timeline` |
| 它写了一份文档 / 代码 | 文档卡逐行高亮 / 代码窗口 | `doc` / `window` |
| 很多结果里挑出几个 | 网格填满 → 少数高亮 | `grid` |
| 别人说 / 评测说 | 引用卡 | `quote` |
| 一句结论收尾 | 发光引用（单独一层，在演示区下方） | `glow-quote` |

规则：
- **一拍 = 一个意思**，3–8 秒；口播换意思就换拍，不要一拍撑十几秒（导演检查会报"画面静止"）。
- **同一段侧推讲解里，演示样式要跟着内容变**：3 拍以上全用同一种组件会被 lint 提示（除非内容本来就是同一类，比如连讲三个功能）。
- 拍与拍之间默认"前推后退"（新拍从前方落定，旧拍后退、变暗、虚化后淡出）；`swap: "slide"` 改成上滑翻页。
- 演示区里的文字全部来自口播原话或其直接概括，不替博主编造功能或数字。
- 演示区自带一层柔和暗场（只压暗、不模糊），让内容从文字墙/画面里浮出来；`plate: false` 关闭。

## 4.6 外观与版式轮换（4:3 和竖屏尤其要做，用户 2026-11-08 要求）

竖拍人物放进 4:3 或 9:16 时，最容易做成"一面墙 + 一张人物卡用到底"，看起来单一。参考风格 A–D 的做法是：**换章节就换底色，人物在几种形态之间切**。

**外观（scene.look）**（样张：[looks_gallery.jpg](looks_gallery.jpg)）：一个章节（约 2 段、10–25 秒）共用一个 look，下一章换。`dms.py scaffold` 会先排好一版，导演检查「样式单一」会查。

| look | 来自 | 适合 |
|---|---|---|
| `b-film` 暗胶片 | B | 开头钩子、态度句、产品 |
| `a-blue` 纯蓝色块 | A | 讲解段、SHOW TIME |
| `b-paper` 米白纸 | B | 理性叙述、步骤、总结 |
| `d-neon` 霓虹紫 + 斜体章节水印 | D | 术语、概念（`look: {"name":"d-neon","text":"SKILL"}` 写水印字） |
| `a-violet` 紫色过渡 | A | 章节之间、锚点页 |
| `a-lime` 荧光绿色块 + 巨字 | A | 数量、节奏、反差 |
| `d-hud` HUD 暗蓝 | D | 数据、系统、执行中 |
| `a-thumbs` 倾斜作品墙 | A | 成果展示、证据蒙太奇 |
| `c-wall` / `c-wall-gold` 品牌文字墙 | C | 回到"家"的底，一条片子里不要连续超过 25 秒 |
| `a-red` 红色放射 | A | 结尾喊话、CTA、情绪高点 |

**人物版式菜单（按画幅轮换，圆窗每章换角落）**

| 画幅 | 轮换顺序（scaffold 默认） | 要点 |
|---|---|---|
| 16:9 横拍 | 全屏 → 侧推 → 圆窗右下 → 全屏（推近）→ 方卡右 → 圆窗左上 … | 全屏段每 8–15 秒推近一次（`zoom: 1.14, dur: 0`） |
| 4:3（多为竖拍素材） | 方卡居中 → 侧推右 → 圆窗右下 → 方卡左 → 侧推右 → 圆窗左上 → 方卡右 … | 竖拍不要用"居中竖条 + 模糊铺底"撑满全片，方卡放在章节色底上（风格 A 的"纯蓝底 + 人物方卡"）；方卡左右换边，内容放另一侧 |
| 9:16 竖屏 | 全屏 → 侧推（上方人物卡 + 下方演示区）→ 全屏推近 → 小方窗右上 → 人物卡上方 → 全屏 → 小方窗左上 … | 全屏时 MG 放在头顶上方或胸前空白处，不压脸；章节色只在人物缩小时露出来，所以缩小的段落要换 look |
| 结尾 | 大圆居中 + `a-red` | 直接对观众喊话 |

## 5. 翻页的连续性（高级感的来源）

1. **环境层连续**：同一主题的几段共用一面文字墙/同一种底色，墙在慢速平移；换章节才换底色。文字墙用使用者自己的品牌两行字（`brand.wall`：主行品牌名、副行英文名/口号）；按**文字墙标准**（用户定稿）：主标识粗黑实心灰、副行皮肤色提亮、错位交叉不留空缝、整面墙统一柔焦 5px 但墙字可读、水平不倾斜，前景背后不加局部模糊；`bg-wall` 只写 skin，参数用默认；要库原貌用 `layout:'library'`（倾斜 −5°）；16 套皮肤按选题挑（科技 acid / 商业 gold / 极简 platinum / 东方 song、lacquer）。两套底色交替（暗色 ↔ 米白纸）本身就是章节信号（B1）。
2. **对象跨句承接**：同一个窗口/文档/手机连续承载多句口播，内部状态推进（缩放到对话区 → 缩放到工具调用 → 拉回全屏），不因为换句就换卡（本技能样片 21–52 秒：一个窗口持续 30 秒，右侧面板四次换内容）。
3. **方向一致**：横移转场旧画面向左出、新画面从右入，全片同一方向（阅读方向 = 时间方向）。
4. **人物是锚点**：转场时人物窗不跟着内容一起飞走，它在画面里平滑换位，观众的眼睛有落脚点。
5. **转场选择**：同话题推进用 `push-left`；进入证据/细节用 `zoom-in`；情绪爆点用 `whip` / `flash`；进入录屏或"现在我们来看一下"用 `line`（荧光线闪切）；结尾用 `iris`（从人物位置展开）。换章节用 `wipe-diag`；揭晓结果用 `split`；进入一张卡/一个窗口用 `rect`；列举切换用 `blinds`；章节开头的品牌时刻用 `text-mask`；**同一个对象跨两段口播**（标题从大字缩到角落、卡片从中间移到左边）用 `morph` + 两层同名 `share`，这是连续性最高的写法。口播说到翻页 / 翻书、或几个话题快速切换时用 `page`（翻走）→ `page-back`（翻回），每页只放一个大标题。全片 2–3 种转场为主，重点时刻才用 `morph` / `text-mask`。
6. **质感**：运动模糊、卡片落地投影、弹性落定、光泽扫过默认开启，不用手写；只有极简风格（风格 C）可整片关掉光泽 `"sheen": false`。

## 6. 画面密度与版式

- 每屏 1 个主焦点 + 最多 2 个辅助焦点；信息密集段留白 15–20%，普通讲解 20–30%，人物强调 30–40%。
- 人物全屏时 MG 只占画面空白侧 25–35%，从不压脸（风格 C）。
- 字幕区（横屏下 14%、竖屏下 18%）不放内容；`lint` 检查下沿 > 0.86。
- 大字 ≤ 12 字，胶囊 ≤ 8 字，数字永远配单位小字。
- 小圆窗必须看得到双眼、嘴巴和下巴（引擎自动按人脸放大，`face: auto`）。
- **版面要满（用户 2026-11-17）**：人物让出的那一侧不能只放一个小动效。一句话的画面 = 一个主动效（`zone-main`）+ 一个辅助（`zone-aside`：数字胶囊、关键词、真实截图、标签），或者一个占满 `zone` 的大动效；动效大小和人物大小相当，不要"人小、动效小、背景大"。
- **接力不留空**：说到下一句之前，上一句的动效留在画面上，下一句的动效出现时再替换；`direct` 报「版面太空」「动效断档」要改。
- **三画幅分别看**：16:9 内容区在人物旁边（左右分主副）；4:3 更窄，主副改上下叠；9:16 内容区在画面中下部、字幕上方，用宽而矮的动效。

## 7. 字幕

- 底部居中，白字黑描边、无底板（`clean`）；资讯/教程类可用黑胶囊（`pill`）；情绪类用超粗黑描边（`bold`）。
- 关键词染色（`highlight`），一条 ≤ 16 字（竖屏 ≤ 12 字），按语义断句，不把一个词劈成两行（引擎按词边界自动断行，标点不进行首）。
- **关键词随口播点亮**：高亮词先是白字，说到那个字的一刻变色 + 外发光一闪 + 纵向轻弹再落定（`pop`，默认开）；一条字幕最多 1–2 个高亮词，高亮的词画面上要有呼应（导演检查会查）。
- 每秒不超过 8 个字，停留不短于 0.5 秒，超过两行就拆条（导演检查会查）。
- **先润色再对齐**：助手把识别稿改成通顺的字幕行（改错字、去口癖、加标点），`dms.py subs` 自动对齐时间。
- 默认用 ASS 烧录，同时导出 SRT，剪辑软件里还能改。

## 8. 声音

- **每个画面动作有一个接触点音效**：弹出 pop、滑动 whoosh、印章 stamp、打字 typing、点击 click、数字滚动 roll、完成 success、警示 error、彩纸 confetti……组件自带默认音效，落在动作的接触帧。
- 同类音效 80ms 内只保留一个，连续同类自动递减音量，避免"提示音轰炸"。
- **默认不加背景音乐**（用户要求）。**例外：片头 solo**（口播前的纯动效展示）配卡点配乐：`music.range` 只在 solo 里出声，120 BPM 每 2 拍（1 秒）切一个动效，转场落在拍点，最后一下 impact 收住再进人物，口播开始前淡出。音效优先用 `assets/sfx/` 的 CC0 真实采样（每次随机选一个变体、±4% 音高），没有采样的种类用合成兜底。
- **用户要求配乐时**才跟内容情绪选：科技/工具 `tech-pulse`；轻快教程 `bright-pop`；讲故事 `lofi-warm`；大事件 `cinematic-rise`；搞笑反转 `comic-bounce`；深度思考 `calm-ambient`。说话时自动柔和闪避（约让 3~5 dB），停顿和高潮时抬起；成片里配乐约比人声低 11 dB，要能听见但不抢人声。
- 交付响度 −15 LUFS、真峰值 ≤ −1 dBTP；人声永远最清楚。
