# 动效质量标准（新做动效、编排画面时的质量关）

用户 2026-11-08 定：用户分享过的几位参考博主（风格 A–D，逐片拆解见 reference-videos.md）的剪辑动效、包装、MG 动画**都是质量参照**——哪里进、哪里出，同一页面上丝滑连续的演示，都要学。**风格 C 最贴近用户的口味**（同等合适时优先它的做法），但只要某种风格的做法更适合眼前这段内容，就用那种。目标只有一个：**质量提上去，样式要高级**。参考博主一律只写风格代号，不写名字。

## 一、各风格最值得学的地方

| 风格 | 学什么 | 适合 |
|---|---|---|
| A 章节色块讲解 | 段内每 1–2 秒点亮一个元素；情绪词巨字 + 斜印章；反转 = 划掉 + 盖章；人物窗四态切换时**过渡色块里人物不动当锚点** | 节奏紧凑的讲解、情绪点多 |
| B 一屏一信息·编辑台 | 每屏只讲 1 件事，巨字/巨数字占 40–60%；眉标编号做目录感；打字机、划掉重写、逐行升起、空心→实心等**文字动效**；两套底色交替 = 换章节 | 观点、金句、清单、纯图形段 |
| C 连续 MG 叙事 | **少而连续**：一个对象/隐喻贯穿多句、内部状态推进；**无限画布横移**（旧对象左出、新对象右入，方向全片一致）；人物窗口化后和产品并列滑动；同一面文字墙当"空间" | 工具介绍、概念讲解、长内容（用户首选） |
| D 霓虹房·术语科普 / 教程 | 录屏为主体时点击处放大 + 光标高亮 + 便签；人物侧推 + 叠卡讲功能；每 60–120 秒一张章节目录卡回顾进度 | 教程、选型、术语 |

## 二、进与出（每个元素都要有交代）

- **从哪来**：从它在空间里"该在的方向"进来——列表从上往下、时间从左往右、下一页从右边、数据从基线长出来、弹窗从触发点放大。不要所有东西都从中间淡入。
- **怎么落**：虚化→清晰 + 上浮/滑入 + 轻微回弹落定（`settle`），落定那一帧有接触音效。
- **到哪去**：退场有方向（被下一页推走、缩回来源、后退变暗淡出），不能突然消失；一页里先进的先出。
- **同时只有一个主动作**：同一时刻主焦点只动一个，其他元素静止或微动；动作之间错开 0.1–0.3 秒。

## 三、同一页面上的连续演示

- 先给"舞台"（窗口、卡片框、文档、手机），再在舞台里逐个点亮内容；舞台在这一段里**不换**，内容在里面推进。
- 状态推进优先于换卡：数字跳涨、进度走满、清单打勾、标注逐条出现、液面升降、图形变形。
- 换页用连续过渡（推、滑、承接 `morph`、镜头推拉），全片方向一致；硬切只用在节奏点或进入录屏。
- 一页信息逐个累加到完整，再整体翻走；每页 4–12 秒。

## 四、高级感的细节

- 留白：信息密集页留 15–20%，普通讲解 20–30%；一屏最多 1 个主焦点 + 2 个辅助。
- 层级：标题 / 数字 / 正文三级字号拉开（约 3 : 1.6 : 1），数字配小字单位。
- 质感：投影随高度变化、玻璃或细描边、一次光泽扫过、运动模糊；颜色不超过 主色 + 强调色 + 中性色。
- 节奏：口播说到关键词的那一刻动作落定（提前 0.1–0.2 秒起动作）。
- 不抢人：人物全屏时动效只占空白侧 25–35%，从不压脸和字幕区。

## 五、新动效交付前自检（`effect check` 出样张后逐条看）

1. 每个元素的进、落、出都有交代吗？方向符合空间逻辑吗？
2. 关键状态落在口播的那个字上吗？
3. 同一时刻是不是只有一个主动作？
4. 16:9 / 4:3 / 9:16 三种画幅里有没有溢出、挤、压人、压字幕？
5. 和同一段的其他元素是"连续的一页"，还是又换了一张卡？
6. 放到参考博主的片子里，会不会显得粗糙？会的话继续改。

`effect.json` 里用 `ref` 写清楚参考了哪种风格的哪种做法（如 `"ref": "C2 无限画布横移"`），只写代号。
