# 封面（成片渲染完自动出一套）

`dms.py render` 出完成片后自动调用 `dms.py cover`，在成片旁边的 `<成片名>_封面/` 和工程的 `cover/` 里各放一套；`dms.py export` 把它们复制进 `deliver/封面/`。也可以单独跑：

```
python dms.py cover <工程>                      # 自动判断有没有真人
python dms.py cover <工程> --person no          # 强制出文字 + 背景版
python dms.py cover <工程> --frames 12.3,40.1,70.2   # 手动指定 A/B/C 三帧（母版秒数）
python dms.py render <工程> 成片.mp4 --no-cover  # 这次不出封面
```

## 开工时问的封面问题（用户 2026-11-20 定）

每次剪辑前和画幅、帧率一起问，见 SKILL.md 第 0 节：
1. **是否同时生成封面**：默认生成；不要就在 edit.json 写 `"cover": {"enabled": false}`。
2. **选哪种风格**：先发 `assets/cover/风格样张.jpg` 给用户看三种风格（A 手账贴纸 / B 科技海报 / C 电影海报），再问：三种都出（默认）/ A / B / C / 我发一张参考封面。
   - **默认三种都出**，选了某一种就把那种排在交付说明最前面。
   - **用户发来参考封面**：本期另做一版「参考图风格」封面（版式、配色、字体气质、元素位置照参考图），文案仍按下面的提炼规则来；照样出三种内置风格做对比。
3. **封面要不要有人物**：要 / 不要（文字 + 背景版）/ 从视频里自动挑（视频里有真人出镜时）。
4. **选了"要"**：提醒用户**提前准备封面人物素材**——一张清楚的人物图，姿势和手势按想要的封面来（抬头、张开手、手托下巴……）。拿到后写进 `cover.photo`，引擎自动抠像、调色，按三种风格排版。

**各 Agent 怎么准备这张人物图**（2026-11-20 查证）：

| Agent | 能不能生图 | 怎么做 |
|---|---|---|
| Codex | 能。内置 `$imagegen`，用 gpt-image-2，支持编辑图片 | 把人物照片 + 参考封面（或姿势描述）给它，生成一张带指定姿势的人物图，存进素材文件夹 |
| 豆包 | 能。「AI 创作 → 图片生成」用 Seedream 5.5，可以上传图片编辑 | 同上，在豆包里上传人物照和参考图生成 |
| WorkBuddy | 能。内置腾讯混元生图（hunyuan-image-v3.0-art） | 能生图；按人物照片改姿势的效果还没实测，第一次用时先试一张，不行就改用 Codex / 豆包 |
| Claude | **不能生图** | 请用户用别的工具生成好、或拍好照片发过来；Claude 只在这张图上加标题、真实 logo 和元素，排成三种风格 |

- 人物图只用使用者本人（或已授权的人）的照片，不用网上的真人照片。
- 生成时说清：保持本人五官不变，只改姿势、手势和表情；背景越干净越好抠（纯色背景最好）；竖构图、留出头顶空间。

## 封面怎么写：从逐字稿提炼 + 爆款结构（用户 2026-11-20 定）

**内容提炼**：先读本期逐字稿（`work/subs.json` / 口播稿），找出三样东西，全部来自口播原话：
- **钩子**：最抓人的一句结论、反差或问题（"一次发两个""便宜两成""凭什么免费"）；
- **对象**：讲的是谁 / 什么（产品名、公司名、人名）——配真实 logo 或真实截图；
- **证据**：口播里的数字或事实（"-20%""+5.2""不到 1/3"）——做成数字徽章。

**爆款封面结构**（抖音、视频号、B 站、YouTube 通用）：
1. **吸引眼球**：主标题两行、每行 4–8 字，第一眼读得出"发生了什么 / 能得到什么"；只有一个高亮词；缩到 260 px 宽还看得清。标题句式用结果型、数字型、痛点反问、门槛型、反差型之一。
2. **好看**：前景和背景对比鲜明（见下文对比度规则）；元素不超过 3 种（截图 / 数字徽章 / 便签）；人物占画面约 1/3，手势或视线朝向标题。
3. **风格统一**：只用内置三种风格（或用户给的参考风格），同一系列的视频固定用同一种，主页宫格看起来整齐。

**交付**：视频剪完后给用户三种风格的封面（竖 3:4 + 横 4:3 各一张，共 6 张 + 总览）；用户发了参考封面就再加一版参考图风格。交付时顺带问一句："有想要的封面风格吗？发参考图过来，下一版按它做。"

## 交付规格

- 3 种风格 × 横竖两版 = 6 张 PNG，外加一张 `封面_总览.jpg`：
  - 竖屏 3:4 = 1080 × 1440（主页宫格，抖音 / 视频号通用）
  - 横屏 4:3 = 1440 × 1080
- 横版和竖版各自独立排版，不是互相裁出来的。
- 避让区：竖版底部约 12% 和左上角 160 × 90 不放关键文字和人脸；横版四边各留约 5%。
- 主标题缩到约 260 px 宽时仍要一眼读得出来。
- 文字最多三层：主标题（两行、每行 4–8 字）→ 高亮词（从主标题里挑 1 个，换对比色或加色块）→ 副标题（约主标题的 1/3，放进飘带、胶囊或色条）。
- 话题元素（截图、数字徽章、便签）每张不超过 3 种，不能抢主标题。

## 三种风格

| 风格 | 背景与配色 | 文字 | 人物 | 适合 |
|---|---|---|---|---|
| A 手账贴纸 | 米白纸 `#F6EFE3` + 淡网格；黑字、橙红高亮 `#FF5A1F` 配黄色马克笔底、深蓝飘带 | 粗黑体，英文用得意黑斜体 | 抠像后加白色 16px + 细黑描边，做成贴纸 | 教程、经验分享、实测 |
| B 科技海报 | 产品品牌色渐变（`cover.colors`）+ 光斑、细网格；玻璃卡 | 白色厚重大字；高亮词放进深色胶囊；副标题是白底胶囊 | 柔光融入背景 | 以工具名 / 产品名为核心的选题 |
| C 电影海报 | 暗调 `#0B1620`，青色体积光 + 金橙光源，颗粒感 | 亮黄大字、黑描边、外发光；高亮词红色；角上一行英文小字（`label`） | 青色轮廓光 + 暖色补光的电影调色 | 观点、对比、商业、大事件 |

## 前景与背景必须鲜明对比（用户 2026-11-13 定，所有封面都要遵守）

封面是设计作品，要和设计美学挂钩：**前景色（文字、图片、人物）和背景色必须形成鲜明对比**。三种风格本身不变，只管颜色搭配。
- **失败的情况**：深色字压在深色底上，比如深紫色字放进黑色胶囊，字和底完全糊在一起、看不清。
- **合格的情况**：浅色背景 + 深色文字和图片（A 风格的做法）；深色背景 + 浅色文字（C 风格的做法）。
- **模板自动做的事**：每一处文字都按 WCAG 对比度检查，大字（≥ 48px）至少 3:1，其余至少 4.5:1。被检查的是文字色和它实际落在的底色：自己的色块；半透明色块要先和页面背景混合；没有色块就取页面在那个位置的背景色。
  - B 风格高亮胶囊（深色底）里的字色，按"品牌主色 → 副色 → 亮黄 → 白"的顺序取第一个看得清的；`cover.colors` 填了深色品牌色也不会再出现深字压深底。
  - B 风格白胶囊副标题，取两个品牌色里更深的那个，不够深就自动加深。
  - B 风格数字徽章用深色玻璃底 + 白字，渐变背景再亮也看得清。
  - C 风格数据卡提亮了底色，加了亮色边框和外发光，不再和暗背景糊在一起。
  - C 风格的真人身后加一盏青色背光，把深色衣服和暗背景分开。
  - 检查后还不够的：色块里的字自动换色，必要时把底换成相反深浅；浮在背景上的大字加反差描边和投影。仍有偏低的会在日志里打印"[对比度] …"，看到就要改配色或文案。
- **写 `cover.colors` 时**：B 风格的渐变底上要放白色大字，两个颜色不要都选很浅的颜色（比如浅黄 + 浅橙）。

## 有真人 / 没有真人

**判断**：人物窗（`presenter.keys`）在某段不是 `hidden`，且母版里检测得到人脸，就算有真人。只在人物可见的区间里找帧，不会拿录屏段落或片头来凑；`cover.person: false` 强制出文字版。

**有真人（P 版）**：
1. **选帧**：在人物可见区间里均匀抽约 160 帧，按下面几项打分，挑出 3 帧（A / B / C 各用一帧，时间互相错开），也可以用 `cover.frames` 手动指定。
   - 人脸清楚可信，头顶和两侧没被画框截掉；
   - 脸部清晰，和 0.2 秒后的画面比变化小（不在眨眼、甩头或运动模糊）；
   - 正脸加分；
   - 抠像完整度：头顶有留白，两侧不贴边（手和肩完整），脸下方有身体；头部两侧抠得太宽（椅背、柜子被一起抠进来）的帧扣分。
2. **抠像**：背景是绿幕就用色键并去绿边；否则用 MODNet 人像抠图（首次使用自动下载约 25MB）。两种都不行时退回"照片卡"：把整帧做成圆角照片放进版面，照样能出图。
3. **美化**：只做轻度处理，包括提亮暗部、调整色温和对比、轻磨皮（保留皮肤纹理）、轻锐化。**不瘦脸、不改五官、不去痣、不镜像**。A / B / C 三版各自调色。
4. **排版**：人物在右下。被原画面截断的边贴着画布边（右边被截就贴右边，左边被截就在左侧做渐隐）；标题和元素放在另一侧，手势或视线尽量朝向标题。

**没有真人（T 版，文字 + 背景）**：
- 标题更大，竖版居中。
- 话题元素放在标题下面（竖版）或右侧（横版）。
- 背景加风格装饰：A 星星和手账纸；B 品牌色渐变、超大水印字和玻璃球；C 体积光、地平线光弧和暗色大字。

## edit.json 的 cover 字段

全部可选；没写时用 `title`（片名）自动拆成两行，高亮词取字幕高亮里出现在标题中的第一个词，并在日志里提示"建议补上 cover 文案"。**每期交付前都应该写**——标题按封面规范写（结果型、数字型、痛点反问、门槛型、反差型），数字和结论只能来自口播原话。

```jsonc
"cover": {
  "title": ["同一句提示词", "Claude 夯爆了"],   // 两行，每行 4–8 字；也可写成 "同一句提示词 / Claude 夯爆了"
  "hl": "夯爆了",                                // 唯一的高亮词，必须出现在 title 里
  "sub": "中等推理 vs 高推理 · 全是代码画的",     // 副标题，**加粗** 会换成强调色
  "note": "不是**视频模型** / 纯代码动画",        // 便签（A 黄便签 / B 深色胶囊 / C 金边条），" / " 换行
  "badges": [{"t": "10×", "d": "响应速度"}, {"t": "1/5", "d": "成本"}],   // 数字徽章，最多 3 个
  "shots": [                                       // 话题截图，最多 2 张
    {"t": 50, "crop": [0.515, 0.14, 0.47, 0.57], "label": "中等推理"},   // 母版某一秒 + 裁切区域（归一化 x,y,w,h）
    {"src": "截图/界面.png", "label": "高推理"}                           // 或直接给图片（相对 edit.json）
  ],
  "colors": ["#5B3BE8", "#FF7A1A"],               // B 风格渐变（取选题产品的品牌色）
  "label": "AI TOOLS · REAL TEST",                // C 风格角上的英文小字，默认用文字墙副行
  "person": "auto",                                // auto / true / false
  "photo": "素材/封面人物.png",                    // 准备好的人物图（一张，或 [A, B, C] 三张）；有它就不从视频里挑帧
  "frames": [12.3, 40.1, 70.2],                    // 可选：手动指定 A/B/C 的人物帧（母版秒数）
  "A": {}, "B": {"title": ["Claude vs Codex", "半年 vs 两周"], "hl": "Claude"}, "C": {}   // 单个风格覆盖任意字段（三版标题不一样时用）
  // "enabled": false  这期不出封面
}
```

## 字体

封面标题优先用这些字体：`assets/fonts/` 里放的字体文件（自动注册，排在最前）→ 阿里巴巴普惠体 3.0 → 思源黑体 → Noto Sans SC → 苹方 → 微软雅黑。英文用 Inter / Montserrat / Poppins / Arial Black。要更厚重的标题，把免费商用的超粗字体（如阿里巴巴普惠体 Heavy、优设标题黑）放进 `assets/fonts/` 即可。

## 交付前自检（看 `封面_总览.jpg`）

- [ ] 6 张齐全，三种风格区分明显，不互相雷同
- [ ] 前景和背景对比鲜明：没有深字压深底、浅字压浅底，日志里没有"[对比度]"提醒
- [ ] 人物：五官没变形，痣还在，没镜像；抠像边缘干净，没有把椅背、柜子抠进来（有的话用 `cover.frames` 换帧）
- [ ] 主标题在缩略图尺寸下仍然清晰；只有 1 个高亮词；文字不超过 3 层
- [ ] 人脸和关键文字没进避让区；人物动作、表情和标题情绪匹配
- [ ] 文案、数字都来自口播原话；截图来自本期素材
