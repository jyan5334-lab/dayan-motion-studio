# 封面（成片渲染完自动出一套）

`dms.py render` 出完成片后自动调用 `dms.py cover`，在成片旁边的 `<成片名>_封面/` 和工程的 `cover/` 里各放一套；`dms.py export` 把它们复制进 `deliver/封面/`。也可以单独跑：

```
python dms.py cover <工程>                      # 自动判断有没有真人
python dms.py cover <工程> --person no          # 强制出文字 + 背景版
python dms.py cover <工程> --frames 12.3,40.1,70.2   # 手动指定 A/B/C 三帧（母版秒数）
python dms.py render <工程> 成片.mp4 --no-cover  # 这次不出封面
```

## 开工时问的封面问题（用户 2026-11-20 定，2026-11-23 改：每次都问全，不沿用上一次）

**每一条新视频都把下面每一题问一遍**，不能因为上一期答过、或者工作库里有配置就跳过、直接默认——每次的思路可能不一样。上一次的回答只能作为选项里的一项「沿用上次：……」，让用户自己点。用户在这次的请求里已经明确说了的项才跳过。放在视频设置之后，**分步问**，每一步等回答再问下一步：

1. **要不要封面**（单独一个弹窗）：同时生成（默认）/ 不要封面（写 `"cover": {"enabled": false}`，后面不问）。
2. **封面怎么做**（`cover.mode`）：
   - **按口播自定义**（`custom`）：不用模板，AI 读本期标题和口播，自己定配色、元素、版式（见下文「自定义封面」）；
   - **用模板**（`template`）：A 手账贴纸 / B 科技海报 / C 电影海报；
   - **两种都出**（`both`）：模板 + 自定义，方便对比；
   - 我发一张参考封面：按参考图做一版（自定义封面的一种，版式、配色、字体气质照参考图）。
3. **选了模板**：先发 `assets/cover/风格样张.jpg`（`dms.py show 风格样张`：Markdown 图片行贴进回复正文 + 在用户电脑上打开；只读图用户看不到），再问：三种都出 / A / B / C（`cover.styles`）。
   **选了自定义**：问出几套（1 / 2 / 3 套，每套横竖各一张），以及风格方向：AI 按口播自己定（默认）/ 我说个方向（用户在对话里打字）/ 发参考图。
4. **封面有没有人物**（自定义和模板都要问）：有人物 / 没有人物（文字 + 背景版）。
5. **选了有人物**：人物从哪来——工作库里的人物图（列出可用的文件夹或总览图，让用户点编号，或说"随意"由 AI 按每套风格挑合适的动作）/ 我自己准备新图 / 从视频里自动挑（有真人出镜时）。

## 封面怎么写：从逐字稿提炼 + 爆款结构（用户 2026-11-20 定）

**内容提炼**：先读本期逐字稿（`work/subs.json` / 口播稿），找出三样东西，全部来自口播原话：
- **钩子**：最抓人的一句结论、反差或问题（"一次发两个""便宜两成""凭什么免费"）；
- **对象**：讲的是谁 / 什么（产品名、公司名、人名）——配真实 logo 或真实截图；
- **证据**：口播里的数字或事实（"-20%""+5.2""不到 1/3"）——做成数字徽章。

**爆款封面结构**（抖音、视频号、B 站、YouTube 通用）：
1. **吸引眼球**：主标题两行、每行 4–8 字，第一眼读得出"发生了什么 / 能得到什么"；只有一个高亮词；缩到 260 px 宽还看得清。标题句式用结果型、数字型、痛点反问、门槛型、反差型之一。
2. **好看**：前景和背景对比鲜明（见下文对比度规则）；元素不超过 3 种（截图 / 数字徽章 / 便签）；人物占画面约 1/3，手势或视线朝向标题。
3. **风格统一**：同一系列的视频固定用同一种风格（模板或某一套自定义），主页宫格看起来整齐。

**交付**：按用户选的方式出——模板每种风格竖 3:4 + 横 4:3 各一张；自定义每套同样横竖各一张；外加 `封面_总览.jpg`。交付时顺带问一句："有想要的封面风格吗？发参考图过来，下一版按它做。"

## 元素环绕人物（用户 2026-11-23 定，模板和自定义都执行）

封面上的标题、徽章、截图、便签要**围着人物排**：贴着人物轮廓、利用人物身边的空隙，只要不压到人物，边缘留一点距离即可（默认约画面短边的 2%）。**不能把元素都堆在画面另一侧、和人物之间空出一大块。**

- 引擎做法：`dms_cover.py` 抠像后算出人物逐行的左右轮廓（`prof`），`assets/cover/cover-kit.js` 按轮廓排版——
  - `KIT.free(y0, y1)`：这几行人物两侧还空着的区间；人物头顶上方没有人的行可以排得更宽（标题常常跨在头顶上方）。
  - `KIT.fitTitle(el, 最大字号, 最小字号, {top})`：标题每一行都要放进它所在那几行的空区间，放不下就缩字。
  - `KIT.flow(元素, {top, bottom})`：把元素一层层排进人物旁边，**每一层贴着人物那一侧对齐**；空间不够整体缩小，空间多就放大并均匀铺开；单个太宽的元素先找更宽的位置再自己缩，不拖累别的。
  - `KIT.audit()`：检查「压到人物」「离人物太远」（同一高度上最靠近人物的元素和人物之间空出超过画面宽 12%）「出画布」，日志里出现 `[排版]` 就要改。
- 模板（A/B/C）有抠像人物时自动走这套排版；没有抠图模型（照片卡）时退回旧版式。

## 自定义封面（不用模板，用户 2026-11-23 定）

模板三种风格太固定，用户可以选**按口播自定义**：AI 读本期标题和口播，为这一期专门设计封面——配色、背景、元素、版式都按内容来，每套一个 HTML，写进 `cover.custom`。

**怎么设计**（每套都走一遍）：
1. **从口播里找视觉隐喻**：这期讲的是什么"东西"——剪辑 → 剪辑软件界面、时间轴、播放头；迭代 / 踩坑 → 问题单、警示条、版本号；检查 / 提问 → 审片单、红笔圈改、印章；新闻 → 报纸版面；价格 → 小票、价签……背景和元素都长成这个东西的样子，不用通用的渐变 + 玻璃卡。
2. **配色从隐喻来**：产品品牌色、那个"东西"本来的颜色（警示黄黑、审片纸红笔、工程黑 + 选中青），一套最多 1 个底色 + 2 个强调色；前景背景对比要鲜明（`KIT.contrast` 会查）。
3. **文案**：标题两行、一个高亮词，全部来自口播原话（钩子 / 对象 / 证据，同上文提炼规则）；几套之间标题可以不同（每套抓一个不同的钩子）。
4. **元素 2–4 种**：都要和本期内容对应（真实数字、真实步骤、真实 logo / 截图）；用 `KIT.flow` 环绕人物排。
5. **几套之间要明显不同**：底色深浅、隐喻、人物动作都错开。人物动作配合标题情绪（指向 → 介绍，握拳 → 决心 / 硬核，托下巴 → 提问 / 思考，抱臂 → 自信 / 对比）。

**写法**：

```jsonc
"cover": {
  "mode": "custom",                       // template（默认）/ custom / both
  "styles": ["A", "B", "C"],              // 模板时出哪几种
  "custom": [
    {"name": "剪辑台", "html": "covers/c1_timeline.html", "photo": "assets/人物_指向.png",
     "title": ["剪辑全是我做的", "他一帧没动过"], "hl": "全是我", "sub": "AI 剪辑助手 · 自述",
     "clips": ["字幕", "动画", "音效", "封面"]},          // 其余字段随这套设计自己定，HTML 里用 KIT.D.xxx 读
    {"name": "审片批改", "html": "covers/c3_review.html", "photo": "assets/人物_托下巴.png", "outline": "sticker"}   // outline: sticker = 白边贴纸描边
    // "person": false = 这一套不要人物；不写 photo 时依次用 cover.photo 里的图
  ]
}
```

HTML 骨架（完整范例在 `assets/cover/custom/`：`剪辑台.html`、`踩坑报告.html`、`审片批改.html`，**只作写法参考，不要当固定模板反复套**）：

```html
<link rel="stylesheet" href="fonts.css"><script src="fontlist.js"></script><script src="data.js"></script><script src="cover-kit.js"></script>
<div id="root"></div><script>
const D = KIT.boot(), W = KIT.W, H = KIT.H, V = KIT.V, px = KIT.px, root = KIT.root;   // V = 竖版
/* 1. 背景和装饰（不跟踪，可以在人物身后） */
(async () => {
  await KIT.fonts();
  if (KIT.PER) await KIT.person(KIT.PER, V ? {x: W*.28, y: H*.34, w: W*.72, h: H*.66} : {x: W*.46, y: H*.08, w: W*.54, h: H*.92}, 'r');
  const t = KIT.el('div', 'ttl', KIT.lines(D.title, D.hl), root);   // .ln 每行，.hl 高亮词
  KIT.fitTitle(t, px(140), px(54), {top: px(70)}); KIT.track(t);
  const nodes = [/* 元素 */];
  KIT.flow(nodes, {top: t.offsetTop + t.offsetHeight + px(40), bottom: H - px(50)});
  KIT.ready('#页面底色');   // 查对比度 + 排版，然后截图
})();
</script>
```

- 选「两种都出」时：模板版用 `cover` 顶层的 `title / hl / sub / badges / shots / note`，自定义版用各自 `custom[i]` 里的文案，两边分别写。
- 同一个 HTML 要同时排得下竖版 3:4 和横版 4:3（`?w=&h=` 传进来），尺寸都用 `px()`（以 1080 为基准）。
- 出完看 `封面_总览.jpg`（每套一列，上竖下横），日志里不能有 `[排版]` 和 `[对比度]`。
- 做得好、用户认可的自定义封面，可以按 `assets/cover/custom/` 的样子存一份进技能，供以后参考写法。

## 交付规格

- 每一套（模板风格或自定义）× 横竖两版 PNG，外加一张 `封面_总览.jpg`：
  - 竖屏 3:4 = 1080 × 1440（主页宫格，抖音 / 视频号通用）
  - 横屏 4:3 = 1440 × 1080
- 横版和竖版各自独立排版，不是互相裁出来的。
- 避让区：竖版底部约 12% 和左上角 160 × 90 不放关键文字和人脸；横版四边各留约 5%。
- 主标题缩到约 260 px 宽时仍要一眼读得出来。
- 文字最多三层：主标题（两行、每行 4–8 字）→ 高亮词（从主标题里挑 1 个，换对比色或加色块）→ 副标题（约主标题的 1/3，放进飘带、胶囊或色条）。
- 话题元素（截图、数字徽章、便签）每张不超过 3 种，不能抢主标题。

## 三种风格

| 风格 | 背景与配色 | 文字 | 人物 | 适合 |
|---|---|---|---|---|
| A 手账贴纸 | 米白纸 `#F6EFE3` + 淡网格；黑字、橙红高亮 `#FF5A1F` 配黄色马克笔底、深蓝飘带 | 粗黑体，英文用得意黑斜体 | 抠像后加白色 16px + 细黑描边，做成贴纸 | 教程、经验分享、实测 |
| B 科技海报 | 产品品牌色渐变（`cover.colors`）+ 光斑、细网格；玻璃卡 | 白色厚重大字；高亮词放进深色胶囊；副标题是白底胶囊 | 柔光融入背景 | 以工具名 / 产品名为核心的选题 |
| C 电影海报 | 暗调 `#0B1620`，青色体积光 + 金橙光源，颗粒感 | 亮黄大字、黑描边、外发光；高亮词红色；角上一行英文小字（`label`） | 青色轮廓光 + 暖色补光的电影调色 | 观点、对比、商业、大事件 |

## 前景与背景必须鲜明对比（用户 2026-11-13 定，所有封面都要遵守）

封面是设计作品，要和设计美学挂钩：**前景色（文字、图片、人物）和背景色必须形成鲜明对比**。三种风格本身不变，只管颜色搭配。
- **失败的情况**：深色字压在深色底上，比如深紫色字放进黑色胶囊，字和底完全糊在一起、看不清。
- **合格的情况**：浅色背景 + 深色文字和图片（A 风格的做法）；深色背景 + 浅色文字（C 风格的做法）。
- **模板自动做的事**：每一处文字都按 WCAG 对比度检查，大字（≥ 48px）至少 3:1，其余至少 4.5:1。被检查的是文字色和它实际落在的底色：自己的色块；半透明色块要先和页面背景混合；没有色块就取页面在那个位置的背景色。
  - B 风格高亮胶囊（深色底）里的字色，按"品牌主色 → 副色 → 亮黄 → 白"的顺序取第一个看得清的；`cover.colors` 填了深色品牌色也不会再出现深字压深底。
  - B 风格白胶囊副标题，取两个品牌色里更深的那个，不够深就自动加深。
  - B 风格数字徽章用深色玻璃底 + 白字，渐变背景再亮也看得清。
  - C 风格数据卡提亮了底色，加了亮色边框和外发光，不再和暗背景糊在一起。
  - C 风格的真人身后加一盏青色背光，把深色衣服和暗背景分开。
  - 检查后还不够的：色块里的字自动换色，必要时把底换成相反深浅；浮在背景上的大字加反差描边和投影。仍有偏低的会在日志里打印"[对比度] …"，看到就要改配色或文案。
- **写 `cover.colors` 时**：B 风格的渐变底上要放白色大字，两个颜色不要都选很浅的颜色（比如浅黄 + 浅橙）。

## 有真人 / 没有真人

**判断**：人物窗（`presenter.keys`）在某段不是 `hidden`，且母版里检测得到人脸，就算有真人。只在人物可见的区间里找帧，不会拿录屏段落或片头来凑；`cover.person: false` 强制出文字版。

**有真人（P 版）**：
1. **选帧**：在人物可见区间里均匀抽约 160 帧，按下面几项打分，挑出 3 帧（A / B / C 各用一帧，时间互相错开），也可以用 `cover.frames` 手动指定。
   - 人脸清楚可信，头顶和两侧没被画框截掉；
   - 脸部清晰，和 0.2 秒后的画面比变化小（不在眨眼、甩头或运动模糊）；
   - 正脸加分；
   - 抠像完整度：头顶有留白，两侧不贴边（手和肩完整），脸下方有身体；头部两侧抠得太宽（椅背、柜子被一起抠进来）的帧扣分。
2. **抠像**：背景是绿幕就用色键并去绿边；否则用 MODNet 人像抠图（首次使用自动下载约 25MB）。两种都不行时退回"照片卡"：把整帧做成圆角照片放进版面，照样能出图。
3. **美化**：只做轻度处理，包括提亮暗部、调整色温和对比、轻磨皮（保留皮肤纹理）、轻锐化。**不瘦脸、不改五官、不去痣、不镜像**。A / B / C 三版各自调色。
4. **排版**：人物在右下。被原画面截断的边贴着画布边（右边被截就贴右边，左边被截就在左侧做渐隐）；标题和元素放在另一侧，手势或视线尽量朝向标题。

**没有真人（T 版，文字 + 背景）**：
- 标题更大，竖版居中。
- 话题元素放在标题下面（竖版）或右侧（横版）。
- 背景加风格装饰：A 星星和手账纸；B 品牌色渐变、超大水印字和玻璃球；C 体积光、地平线光弧和暗色大字。

## edit.json 的 cover 字段

全部可选；没写时用 `title`（片名）自动拆成两行，高亮词取字幕高亮里出现在标题中的第一个词，并在日志里提示"建议补上 cover 文案"。**每期交付前都应该写**——标题按封面规范写（结果型、数字型、痛点反问、门槛型、反差型），数字和结论只能来自口播原话。

```jsonc
"cover": {
  "title": ["同一句提示词", "Claude 夯爆了"],   // 两行，每行 4–8 字；也可写成 "同一句提示词 / Claude 夯爆了"
  "hl": "夯爆了",                                // 唯一的高亮词，必须出现在 title 里
  "sub": "中等推理 vs 高推理 · 全是代码画的",     // 副标题，**加粗** 会换成强调色
  "note": "不是**视频模型** / 纯代码动画",        // 便签（A 黄便签 / B 深色胶囊 / C 金边条），" / " 换行
  "badges": [{"t": "10×", "d": "响应速度"}, {"t": "1/5", "d": "成本"}],   // 数字徽章，最多 3 个
  "shots": [                                       // 话题截图，最多 2 张
    {"t": 50, "crop": [0.515, 0.14, 0.47, 0.57], "label": "中等推理"},   // 母版某一秒 + 裁切区域（归一化 x,y,w,h）
    {"src": "截图/界面.png", "label": "高推理"}                           // 或直接给图片（相对 edit.json）
```

## 字体
