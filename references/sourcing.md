# 联网取材规则：按口播找真实图片和视频（用户 2026-11-20 定）

没有真人出镜、只有一段口播（克隆音频 + 口播稿）的片子，画面要靠真实素材撑起来。素材优先级：**真实截图 / 录屏 / 视频 > 技能里现成的动效 > 现做新动效**。这份文件规定：每种口播该配什么素材、去哪找、怎么取、取到什么程度算合格。

## 一、第一次使用：先把取材的路打通（每个 Agent 只做一次）

开工前跑 `dms.py grab check --agent <claude|codex|workbuddy|doubao>`（用户说"检查连接情况"时也跑它），按结果走：

| Agent | 要求 | 第一次怎么做 |
|---|---|---|
| **Claude**（Claude Code / 桌面版 / 网页版） | **必须装 Chrome 扩展**（Claude in Chrome） | 没连上就对用户说：「为了能更好地获取网上优质素材，从而提升视频质量，请安装浏览器扩展」，给出安装步骤（https://claude.ai/chrome → 添加到 Chrome → 用同一个账号登录，多个组织时选当前对话的组织）。用户装好回来说"检查连接情况"，Agent 用扩展打开 https://github.com/ 截一张图并存成文件，页面是原文、没被自动翻译，才算连上，然后开始剪。 |
| **Codex** | **必须装 Chrome 扩展**（Codex 插件） | 同上的提示语；安装：Codex 应用「插件」→ Chrome → Chrome 应用商店安装 → 同意权限 → Chrome 里确认已连接；网站第一次访问选「始终允许」。用户回来说"检查连接情况"，同样截一张 GitHub 验证。 |
| **WorkBuddy** | 不装扩展，用技能自带的取材命令 | 技能的 `grab shot / grab image / grab clip` 在用户电脑上直接跑（无头浏览器 + yt-dlp），`grab check` 显示"能截真网页"就行。想让 WorkBuddy 自己也能点网页，可在「+ → 技能」里装「浏览器自动化」技能。 |
| **豆包** | 不装扩展，用技能自带的取材命令 | 同 WorkBuddy；豆包「工作任务」第一次操作电脑时会请求授权，请用户允许。 |
| DeepSeek 官方网页版 / App | 跑不了本技能（不能在电脑上执行命令） | 可以把 DeepSeek 当模型接进 WorkBuddy 等 Agent 使用。 |

同时问一次用户是否允许联网取材（`grab allow / deny`，记在本机，以后不再问）。

**用 Chrome 扩展截图的注意事项**：打开网址后先执行 `document.documentElement.setAttribute('translate','no')`；如果页面已经被自动翻译成中文（仓库名、按钮被翻乱），请用户在 Chrome 里关掉英文自动翻译（地址栏翻译图标 →「一律不翻译英语」），再**新开一个标签页**打开；等 3 秒加载完再截图，`save_to_disk` 存文件；截完按内容裁掉两侧空白。截的图拷进素材文件夹，并在 `素材来源.json` 里记一条（网址、时间）。

## 二、看口播配素材：每种说法该找什么

写完编排单后，逐段列一张**素材清单**（段落 · 口播原话 · 要什么素材 · 去哪找 · 用哪个动效承载），然后去取。

| 口播在讲 | 要找的真实素材 | 去哪找 | 怎么取 | 用什么承载 |
|---|---|---|---|---|
| 热点新闻、行业快讯（"昨天 OpenAI 发布了…"） | ① 原始报道页截图（标题 + 导语 + 配图那一屏）② 新闻配图 ③ 官方发布帖 / 公告截图 ④ 发布会或演示视频 3–8 秒 | 官方博客 / 官网新闻页、官方 X / 微博 / 公众号、主流媒体原文（不用转载站、营销号） | `grab shot` 截报道页；`grab image` 取文章配图（og:image）；`grab clip` 截官方视频 | `fx-news-card`、`fx-browser-shot`、`media`、`window`（视频） |
| 产品 / 工具 / 模型名字（Claude、Codex、豆包…） | ① 官方 logo（引擎自带，`logo` 组件 `brand`）② 官网首页截图 ③ 产品真实界面截图 ④ 官方演示视频几秒 | 官网、官方文档、官方发布视频 | logo 不用取；`grab shot` 官网；`grab clip` 官方演示 | `logo`、`fx-browser-shot`、`window` |
| 开源 / 仓库 / Star 数 | 仓库首页（含 Star / Fork 那一行）、README 关键段、Release 页 | GitHub / Gitee 仓库 | `grab shot`（`--selector` 截某块，`--scroll` 往下） | `fx-browser-shot`（`mark` 圈出 Star / Code 按钮） |
| 讲到某个博主 / 某个人做了什么 | 他的主页截图、那条作品的页面截图、作品里几秒片段 | 抖音 / 视频号 / B 站 / YouTube / TikTok / X 主页和作品页 | `grab shot` 主页 / 作品页；`grab clip` 作品片段（**先给用户确认**） | `fx-browser-shot`、`window`、`fx-social-post` |
| 数据 / 榜单 / 报告（"增长了 300%"） | 原始榜单、报告、官方数据页那一屏，数字所在位置 | 发布数据的官方页面、报告原文 | `grab shot`，数字处用 `mark` 圈出 | `fx-browser-shot` + 数字动效（`counter` / `fx-stat-hero`）叠在旁边 |
| 网友评论 / 争议（"评论区都在说…"） | 评论区截图 | 原帖评论区 | `grab shot --selector` 截评论块 | `fx-phone-comments`、`fx-comment-pick`；普通网友的头像和昵称打码 |
| 教程 / 操作步骤（"打开设置，点这里"） | 官方文档页截图；真实操作录屏 | 官方文档；录屏要用户提供或用户允许 Agent 录 | `grab shot` 文档页 | `fx-cursor-tour`、`window`（录屏 + 放大） |
| 对比 / 实测 / 效果展示 | 用户自己往期成片、实测录屏 | 用户工作库 | 直接从工作库取 | `window`、`fx-stack-shots`、`fx-before-after` |
| 跟 AI 对话（提要求、提意见、截图发过去） | 对话本身用 `fx-ai-chat-app` 还原；窗口里附的截图、旁边配的素材仍找真的 | 本期第一版画面、相关网页 | 同上 | `fx-ai-chat-app` |
| 观点 / 情绪 / 概念（没有对应的实物） | 不硬找图，用现成动效表达 | — | — | 动效库（`dms.py catalog 关键词`） |

关键词怎么搜：用口播原话里的**专有名词**（产品名、人名、事件名 + 时间），中文事件优先中文来源，海外产品优先官方英文页面；同一件事至少看两个来源，截原始出处那一个。

## 三、合格标准

**截图**
- 页面是原样：样式完整、语言是原文（没被浏览器自动翻译）、没有弹窗 / cookie 条 / 登录遮罩挡住正文。`grab shot` 会检查样式，没加载全会判失败。
- 截"这句话说的那一块"：新闻截标题和导语，仓库截名字和 Star，数据截数字所在的那一屏；不要整页小字。
- 宽度至少 1000 像素；放进片子时字要看得清（`fx-browser-shot` 里截图按窗口宽度整幅显示，太长就用 `scroll` 滚）。
- 不截需要登录才能看的私人内容；不截别人的私信、订单、个人信息。普通网友的头像和昵称打码。
- 不单独下载真人照片当素材；需要出现某个人时，用他公开主页 / 作品页的整页截图。

**配图**（`grab image`）
- 取文章自己的配图（og:image 或正文大图，宽 ≥ 800），不用搜索引擎里来源不明的图。
- 图片原样使用，不做 AI 改图、不P掉水印、不换文字。

**视频片段**（`grab clip`）
- 每段 3–8 秒，只截口播说到的那个动作 / 画面（`--start` 写到秒）；最高 1080p。
- 优先官方账号发布的视频（发布会、官方演示、官方宣传片）；用户自己的视频随便用。
- **下载后先发给用户看，问"这段能不能用"**，用户说能用 `grab ok`，不能用 `grab no`；没确认的片段 lint 拦住，不能渲染。
- 不去水印、不变速冒充原创；片段里原有的声音默认静音（口播是主声音）。

**来源**：所有素材自动记进素材文件夹的 `素材来源.json`（网址、时间、状态），交付说明照着列出"素材来源"；画面上不用打来源标注。

## 四、取不到时

按顺序换路：本机无头浏览器（`grab`）→ Agent 自己的浏览器扩展截图存文件 → 把缺的素材列给用户（哪段、要什么、网址、截哪里），请用户截好放进素材文件夹。**任何一步都不用生成图、画的假界面冒充真实素材**；实在没有就换成现成动效表达，并在交付说明里写明"这段缺真实素材"。
